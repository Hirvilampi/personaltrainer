# Personal Trainer

Front End Programming course project: a Personal Trainer web application built with **React, TypeScript and Vite**.  
The application consumes an existing REST API for managing customers and training sessions.

**Live demo:**  
https://personaltrainer-orpin.vercel.app/

**REST API documentation:**  
https://juhahinkula.github.io/personaltrainerdocs/

---

## Overview

The Personal Trainer app provides a user interface for managing customers and their trainings.  
It demonstrates modern frontend development practices including component-based UI, REST API integration, data grids, charts, and calendar views.

The project was developed as part of a frontend course assignment.

---

## Features

### Customers
- View customers in a data grid
- Add new customers
- Edit customer information
- Delete customers
- Add trainings to customers

### Trainings
- View all trainings
- Delete trainings
- Calendar view for scheduled trainings

### Data & Visualization
- Interactive tables using **AG Grid**
- Charts and statistics using **Recharts**
- Calendar view using **FullCalendar**
- CSV export functionality
